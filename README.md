## Featured Engineering Projects

### Saksham — Voice-First Learning Companion

[GitHub Repository](https://github.com/ianusha08/saksham)

A real-time voice-based learning companion built using LiveKit Agents, Deepgram speech-to-text, and Murf Falcon text-to-speech.

- Engineered a real-time voice interaction pipeline for natural conversational experiences.
- Implemented conversational memory and interactive learning capabilities.
- Integrated outbound calling, call analytics, human escalation, and specialist-agent handoffs.

**Tech Stack:** Next.js · React · TypeScript · Python · LiveKit · Deepgram · Murf Falcon

### NUURAI — Wellness & Self-Reflection Platform

[GitHub Repository](https://github.com/ianusha08/nuurai)

A React-based wellness platform designed to support daily self-reflection through check-ins, journaling, and personal wellbeing tracking.

- Created daily wellness check-ins and personal journaling features.
- Developed mood, energy, stress, and sleep tracking with an interactive dashboard.
- Prototyped a conversational AI companion for guided reflection.

**Tech Stack:** React · JavaScript · CSS · Vite

### Restricted Area Intrusion Detection System

[GitHub Repository](https://github.com/ianusha08/restricted-area-intrusion-detection)

A real-time computer vision system designed to detect unauthorized entry into restricted areas using webcam feeds and human pose estimation.

- Implemented MediaPipe pose detection and polygon-based restricted-zone monitoring using OpenCV.
- Added a 3-second verification threshold to distinguish genuine intrusions from passing individuals.
- Integrated Twilio SMS alerts, event logging, and a 15-second notification cooldown.

**Tech Stack:** Python · OpenCV · MediaPipe · NumPy · Twilio
